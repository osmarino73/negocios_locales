# Guía Técnica para Agentes de IA: Makloz Tech

Este documento define la arquitectura y reglas que deben respetar los agentes de IA al modificar la landing page de **Makloz Tech**.

## 1. Reglas Principales de Desarrollo
- Mantener la fuente única de verdad en `DATOS_NEGOCIO.json`.
- Preservar la estética **Dark High-Tech Glassmorphic UI** (`#0b1120`, `#0f172a`, `#f97316`).
- Todos los enlaces de acción deben dirigir al WhatsApp oficial `+573004567890`.
- El archivo `index.html` debe mantenerse autónomo (standalone-ready) para empaquetado en `build_standalone.js`.

## 2. Puntos Comerciales Indispensables
- El mensaje del "Sitio Web Gratuito de Regalo" debe destacarse como la estrategia principal de entrada (Gancho $0 COP desarrollo).
- El Agente de IA para WhatsApp y MioWeKids deben posicionarse como las soluciones SaaS de ingresos recurrentes (MRR).
