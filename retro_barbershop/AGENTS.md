# Instructions & Guidelines: Retro Barbershop — Montería

Este proyecto es la landing page oficial de **Retro Barbershop** en Montería, Córdoba.

## 🎯 Regla Mandatoria: Estructura Oficial de Secciones

Toda subpágina o modificación debe incluir estrictamente las siguientes 6 secciones oficiales:
1. `#inicio`: Hero Full-Width Canvas Scroll Scrubbing (300vh, 2 pasos editoriales 50%/50%, poster fallback, overflow-x clip).
2. Franja de Pilares / Garantías (Scroll Snap horizontal en móvil < 768px).
3. `#servicios`: Grid 3 columnas desktop / 2 columnas móvil (Tarjetas Full-Bleed 3:4, degradado aterciopelado inferior, footer 2 filas con precio amplio 100% y enlace minimalista `AGENDAR ➔`).
4. `#nosotros`: Bloque Editorial (Foto de sillones clásicos de barbería `photo-1585747860715-2ba37e788b70`, métricas de autoridad) + 4 Profesionales en Retrato Editorial 3:4.2 (Grid 4 columnas desktop / Carrusel Scroll Snap horizontal con efecto Peek en móvil).
5. `#ubicacion`: Datos de contacto y Google Maps georreferenciado (`https://maps.google.com/maps?q=Retro+barbershop,+Cra.+10+Oe.+%23+43-69+local+1,+Monter%C3%ADa,+C%C3%B3rdoba&t=&z=16&ie=UTF8&iwloc=&output=embed`).
6. Footer Principal: Enlaces, horarios, datos de contacto y módulo de reserva con botón **«Agendar»**.

## 🎨 Unicidad Estricta de Variables CSS

Todos los acentos dorados y camel deben consumir estrictamente las variables CSS `--color-accent` y `--color-camel`. Queda prohibido quemar valores HEX/RGB hardcoded.
