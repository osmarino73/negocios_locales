## 🚀 Cómo usar estos recursos en un nuevo proyecto:

1. Vincular o copiar la imagen Desktop y Mobile desde `assets/heroes/educacion_infantil/`.
2. Consumir `RECURSOS_EDUCACION_INFANTIL.json` para obtener los íconos de las 4 áreas de desarrollo (Arte, Música, Lógica, Naturaleza), textos pedagógicos y plantillas Schema.org.
3. Asegurar que las tarjetas de servicios **no contengan tarifas mensuales**, sino el botón minimalista `SOLICITAR CUPO ➔`.
