# Instructions & Guidelines: Clínica Odontológica Luxury Smile — Montería

Este proyecto es la landing page oficial de **Clínica Odontológica Luxury Smile Montería**.

## 🎯 Regla Mandatoria: Estructura Oficial de Secciones

Toda subpágina o modificación debe incluir estrictamente las siguientes 6 secciones oficiales:
1. `#inicio`: Hero Full-Width Bleed (640px desktop, 720px móvil, anclaje inferior, 60% superior despejado).
2. Franja de Pilares / Garantías (Scroll Snap horizontal en móvil < 768px).
3. `#servicios`: Grid 3 columnas desktop / 2 columnas móvil (Tarjetas Full-Bleed 3:4, degradado aterciopelado inferior, footer 2 filas con precio amplio 100% y enlace minimalista `AGENDAR ➔`).
4. `#nosotros`: Bloque Editorial (Foto de consultorio/clínica odontológica `photo-1629909613654-28e377c37b09`, 4 métricas de autoridad) + 4 Profesionales en Retrato Editorial 3:4.2 (Grid 4 columnas desktop / Carrusel Scroll Snap horizontal con efecto Peek en móvil).
5. `#ubicacion`: Datos de contacto y Google Maps georreferenciado (`https://maps.google.com/maps?q=Cl%C3%ADnica+Odontol%C3%B3gica+Luxury+Smile,+Monter%C3%ADa,+C%C3%B3rdoba&t=&z=16&ie=UTF8&iwloc=&output=embed`).
6. Footer Principal: Enlaces, horarios, datos de contacto y módulo de reserva con botón **«Agendar»**.

## 🎨 Unicidad Estricta de Variables CSS

Todos los acentos cian y teal deben consumir estrictamente las variables CSS `--color-accent` y `--color-teal`. Queda prohibido quemar valores HEX/RGB hardcoded.
